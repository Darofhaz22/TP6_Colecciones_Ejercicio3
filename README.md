# Trabajo Práctico 6 - Colecciones

## Ejercicio 3 - Sistema de Universidad

Este ejercicio consiste en desarrollar un sistema de gestión de profesores y cursos utilizando Programación Orientada a Objetos y colecciones dinámicas en Java.

### Clases

- **Profesor:** representa a los profesores y administra los cursos que tiene asignados.
- **Curso:** representa los cursos y mantiene la relación con su profesor.
- **Universidad:** administra profesores y cursos.

### Funcionalidades

- Agregar profesores.
- Agregar cursos.
- Asignar profesores a cursos.
- Listar profesores y sus cursos.
- Listar cursos y sus profesores.
- Buscar profesores por ID.
- Buscar cursos por código.
- Cambiar el profesor de un curso.
- Eliminar cursos.
- Eliminar profesores.
- Mantener actualizada la relación entre profesores y cursos.
- Mostrar la cantidad de cursos por profesor.

### Conceptos aplicados

- Programación Orientada a Objetos.
- Encapsulamiento.
- Relación bidireccional entre objetos.
- `ArrayList`.
- Búsqueda y eliminación de elementos.
- Asociación entre clases.
- Sincronización de relaciones entre objetos.
- Métodos reutilizables.

### Ejecución

El ejercicio cuenta con su propio `Main.java`, por lo que puede ejecutarse de manera independiente.
